# 天命盤（てんめいばん）

生年月日・姓名・出生地から、**四柱推命の命式**と**算命学の人体星図**、**大運・年運**、**姓名判断**を図と言葉で読み解き、二人の**相性**（恋愛・仕事・友情）も診断する Web アプリです。

外部ライブラリ・サーバー不要の **単一 HTML ファイル**（Vanilla JS + Canvas）で動作します。

## 主な機能

| 機能 | 内容 |
|---|---|
| **命式** | 年・月・日・時の四柱（干支）を太陽黄経の計算で算出（節入り・立春・地方時を補正） |
| **人体星図** | 算命学の陽占を 3×3 に配置し、十大主星 5・十二大従星 3・中心星を表示 |
| **五行・エネルギー** | 五行バランスと、十二大従星による生命エネルギー量 |
| **運の巡り** | 大運（10 年ごと）・年運（毎年）をカードで表示、タップで詳しい解説に展開 |
| **姓名判断** | 五格（天格・人格・地格・外格・総格）・81 画吉凶・三才配置（画数は編集可） |
| **相性診断** | 二人の日主の五行関係・日支/月支の干支関係・五行補完から、恋愛・仕事・友情を採点 |
| **保存・シェア** | 結果を 1 枚のカード画像に描画（長押し／右クリックで保存、Web Share 対応） |

## 使い方

`index.html` をブラウザで開くだけで動作します。ビルドやインストールは不要です。

GitHub Pages を有効にすると、ブラウザから直接アクセスできます。

## 計算・精度について

- **日柱**は暦日ベースで `(ユリウス通日 + 49) mod 60` により算出（2000-01-01＝戊午、2000-01-07＝甲子で検証）
- **月柱・年柱**は太陽黄経を直接計算し、節入り・立春の境界を判定
- **時柱**は出生時刻から算出（出生地の経度で地方時を補正、不明時は補正なし）
- **姓名判断**の画数は新字体・一般的な数え方による推定で、各文字を編集可能（旧字体を用いる流派とは異なります）
- 81 画吉凶は熊崎式ベース、三才は五行の相生相剋による簡易判定

## 免責

本アプリは東洋の命理学（四柱推命・算命学・姓名判断）に基づく **娯楽・自己理解** を目的としたものです。診断結果は運勢の傾向を示す目安であり、重要な意思決定の根拠とするものではありません。
